# Plastic Injection APS

Advanced Planning and Scheduling for Plastic Injection Molding. TED University, CMPE 491, Fall 2026, Group 37.

## Dosyalar

- `index.html`: tüm site (Team ve Documents bölümleri)
- `documents/Project_Proposal_Group_37.docx`: proje önerisi raporu

## GitHub Pages ile yayınlama

1. github.com'da `plastic-injection-aps` adlı, Public bir depo aç.
2. `index.html` dosyasını ve `documents` klasörünü (içindeki .docx ile birlikte) yükle.
3. Settings > Pages bölümünde "Deploy from a branch", `main`, `/ (root)` seç.
4. Birkaç dakika sonra site `https://KULLANICIADI.github.io/plastic-injection-aps/` adresinde açılır.

## Güncelleme

- `index.html` içinde `[e-posta]` yazan yerlere ekip üyelerinin e-posta adreslerini yaz.
- Yeni rapor eklemek için dosyayı `documents` klasörüne yükle ve Documents bölümüne bir satır ekle.
